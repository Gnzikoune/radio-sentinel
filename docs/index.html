Transformez une vieille clé USB en Observatoire Mobile Professionnel

Radio Sentinel combine le détournement d'un modem 3G grand public (*Alcatel X602D*) et un smartphone Android pour cartographier le spectre hertzien, trianguler les pylônes et détecter les fausses stations de base (IMSI-Catchers) à 0 €.

Capacités & Modules Clés

Une suite d'ingénierie télécom complète

🗺️

Cartographie Heatmap Continue

Interpolation spatiale le long des axes de circulation pour générer un dégradé de couverture radio précis (Vert / Jaune / Rouge), directement sur Leaflet avec Google Satellite HD.

⚡

Audit Bi-Réseau & Performance 4G

Compare simultanément deux opérateurs : écoute spectrale brute sur la clé USB (ex. Azur) et performance data réelle sur la SIM du téléphone (débit descendant, latence RTT, ping serveur).

🛰️

Triangulation par Barycentre mW

Convertit les dBm logarithmiques en milliwatts réels pour isoler le centre de gravité des émissions et estimer la position des pylônes émetteurs avec filtre Haversine anti-réutilisation de Cell ID.

🛡️

Détection IMSI-Catcher (Anti-Downgrade)

Détecte les rétrogradations forcées 3G->2G non chiffrées avec alertes visuelles et sonores instantanées pour protéger la confidentialité des communications mobiles.

📱

Appairage par QR Code Intelligent

Bascule automatiquement entre le mode Nomade 4G (tunnel sécurisé chiffré sans coupure en extérieur) et le mode Wi-Fi local à domicile. Zéro saisie d'URL sur le téléphone.

🌐

Export 3D Google Earth & CSV

Génération en un clic de fichiers KML 3D extrudés selon la puissance radio reçue pour visualiser le relief hertzien dans Google Earth Pro, et export CSV compatible QGIS/Python.

Démarrage Rapide

Opérationnel en 3 commandes

# 1. Cloner le dépôt GitHub

git clone https://github.com/Gnzikoune/radio-sentinel.git

# 2. Installer les dépendances

cd radio-sentinel && pip install -r requirements.txt

# 3. Lancer la station

./lancer.bat
