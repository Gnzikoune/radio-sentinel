# 🚀 Guide de Référencement Google & Optimisation SEO de Radio Sentinel

Ce guide récapitule les actions concrètes à mener sur l'interface GitHub et sur le web pour maximiser l'indexation de Radio Sentinel sur Google.

---

## 1. Configuration du Dépôt GitHub (SEO Interne)

### A. Description du projet (Section "About" à droite sur GitHub)
Copiez-collez cette description optimisée pour le moteur de recherche :
```text
Plateforme autonome d'audit spectral 3G/4G, cartographie SIG et détection d'IMSI-Catchers avec une vieille clé USB et un smartphone. 100% open source.
```

### B. Lien du site web (Website URL)
Dans la même section "About", renseignez l'URL de la vitrine GitHub Pages :
```text
https://gnzikoune.github.io/radio-sentinel/
```

### C. Mots-clés GitHub ("Topics")
Cliquez sur la roue crantée à côté de **About** sur GitHub et ajoutez exactement ces 18 tags :
```text
wardriving
rf-mapping
cellular-network
gsm-modem
at-commands
fastapi
cartographie-reseau
telecom
open-source
imsi-catcher
cybersecurity
opencellid
leaflet
python
sdr
gabon
reverse-engineering
hardware-hacking
```

---

## 2. Activation de GitHub Pages en 3 clics

1. Rendez-vous sur votre dépôt : `https://github.com/Gnzikoune/radio-sentinel/settings/pages`
2. Sous la section **Build and deployment** :
   - **Source** : `Deploy from a branch`
   - **Branch** : Choisissez `main` et le dossier `/docs`
   - Cliquez sur **Save**.
3. Dans les 2 minutes qui suivent, votre site vitrine sera accessible à :  
   👉 **`https://gnzikoune.github.io/radio-sentinel/`**

---

## 3. Soumission à Google Search Console

1. Connectez-vous sur [Google Search Console](https://search.google.com/search-console).
2. Ajoutez une propriété de type **Préfixe de l'URL** : `https://gnzikoune.github.io/radio-sentinel/`.
3. Validez avec la balise méta HTML ou par fichier HTML.
4. Cliquez sur **Inspection de l'URL** et demandez une indexation immédiate.

---

## 4. Vérification de l'Indexation Google

Pour suivre la prise en compte par les robots d'exploration Google, saisissez dans la barre de recherche :
```text
site:github.com/Gnzikoune/radio-sentinel
site:gnzikoune.github.io/radio-sentinel
```
